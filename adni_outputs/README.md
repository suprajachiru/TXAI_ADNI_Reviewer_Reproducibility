# ADNI Output Artifacts

This directory is reserved for the output artifacts generated by the
manuscript-aligned five-fold ADNI experiment.

## Important reproducibility note

The ADNI participant-level dataset is access-controlled and is not
redistributed in this repository. Therefore, this package does not contain
fabricated ADNI performance results or placeholder files presented as
experimental evidence.

After the authorized ADNI data and the corresponding patient-level manifest
are supplied, running the implementation in `src/` should generate the
following artifacts in this directory:

- `experiment_config.json`
- `fold_metrics.csv`
- `pooled_metrics.json`
- `oof_predictions.csv`
- `pooled_roc.png`
- `txai_fold1.pt` through `txai_fold5.pt`
- `trustworthy_fold1.json` through `trustworthy_fold5.json`
- `xai_fold1.json` through `xai_fold5.json`

The current repository also contains `reference_oasis_outputs/`, which are
execution artifacts from the openly accessible OASIS reference experiment.
Those files must not be interpreted as ADNI results.

## ADNI source

Official ADNI website:

https://adni.loni.usc.edu

ADNI data access requires the appropriate authorization through the LONI
Image and Data Archive (IDA).

## Expected execution

Set the manifest path in Colab, for example:

    %env TXAI_DATASET=ADNI
    %env TXAI_MANIFEST=/content/adni_data/manifest.csv

Then run:

    python src/TXAI_Reproducibility_Implementation.py

Only outputs generated from the authorized ADNI experiment should be copied
into this directory and subsequently committed to the repository.
